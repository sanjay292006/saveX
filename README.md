## 📌 Overview

**saveX** is a modern personal finance tracker designed to help users manage and understand their financial activity through a clean and intuitive web interface.

The application provides a centralized place to:

- Track income
- Record expenses
- Manage transactions
- Monitor financial activity
- Visualize spending patterns
- Maintain financial records
- Organize personal finances

saveX is built using **React, TypeScript, Vite, and Tailwind CSS**, providing a responsive and modern user experience.

---

# 🎯 Problem Statement

Managing personal finances can become difficult when income and expenses are spread across different applications, notebooks, spreadsheets, or banking platforms.

Users often need a simple way to answer questions such as:

- Where is my money going?
- How much did I spend this month?
- How much income did I receive?
- Which categories consume most of my budget?
- Am I spending more than I earn?
- What does my financial activity look like over time?

**saveX** aims to simplify this process by providing a centralized financial tracking dashboard.
